Token Economy Flow

How tokens move inside JioVibe

The token works like an internal digital value system. Users can buy or earn tokens, spend them on creators and marketplace features, while creators use those tokens for platform tools. This keeps the economy active inside JioVibe.

1 Token Wallet

Tokens are visible inside the JioVibe Wallet. The wallet shows the user or creator’s current balance.

2 User purchases or earns tokens

Users can buy tokens or earn them through tasks, referrals, campaigns, watch-time rewards, and engagement activities.

3 User spends tokens on creators

Users can use tokens for Super Chat, Super Drop, donations, stickers, creator drops, premium access, marketplace rewards, and coupons.

4 Creator uses platform tools

Creators can spend earned tokens on AI editing, thumbnails, captions, translation, boosting, analytics, copyright management, and other creator tools.

5 Tokens come back to platform

When creators consume tools, tokens return to the platform. The platform can again reward users and continue the circular economy.

Key Message: Users earn/spend → Creators earn/use → Platform recycles → Users get rewarded again.
